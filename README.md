# Purrsheen
Files for the Purrsheen lamp released at Toorcamp

![Purrsheen bases in Bambu studio](/sheen.png)

Here is the release of the 3d printed files for the Purrsheen at toorcamp!

This contains the base and power button as .stl files and 3mf files.

The power button file should open correctly as a Bambu Project file, but in the event it doesn't, make sure the object scaling is set to:
X=97% Y=100% Z=88%

Happy Printing!
